# Seu Filme

Aplicação web inspirada em plataformas de streaming, desenvolvida com foco em responsividade, interatividade e organização de conteúdo por categorias.

Acesse o projeto:

[![](https://img.shields.io/badge/demo-online-green)](https://wallissl.github.io/seuFilme/)




## Sobre o Projeto

O **Seu Filme** permite que o usuário navegue por diferentes categorias de filmes como Ação, Comédia, Suspense, Drama e Terror.

A aplicação simula a experiência de uma plataforma de streaming, com destaque para:
- Seção de filmes recomendados
- Navegação por categorias
- Página de *Trending* com layout moderno
- Atualização dinâmica de conteúdo sem recarregar a página



## Funcionalidades

- Navegação por categorias
- Renderização dinâmica com JavaScript
- Layout responsivo (mobile e desktop)
- Menu mobile com hambúrguer
- Scroll horizontal para categorias (mobile)
- Seção Trending com destaque visual



## Tecnologias Utilizadas

  **HTML5**: Estrutura semântica  
  **CSS3**: Estilização, responsividade e layout (Flexbox)  
  **JavaScript (Vanilla JS)**: → Manipulação do DOM e eventos  



## Responsividade

O projeto foi desenvolvido com abordagem **mobile-first**, garantindo uma experiência fluida em diferentes tamanhos de tela.


## Objetivo

Este projeto foi desenvolvido com o objetivo de praticar:
- Manipulação do DOM
- Estruturação de layouts responsivos
- Organização de código front-end sem frameworks
